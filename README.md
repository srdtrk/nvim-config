# Neovim Configuration

Original starting point for my Neovim setup was [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim). It seems like it stopped being maintained for the last 6 months, so I decided to start from scratch and build my own configuration.

# Installation

I use my nixos-config to clone and set up Neovim with this configuration. You can find the relevant part of my nixos-config [here](https://github.com/srdtrk/nixos-config/blob/main/modules/shared/files.nix).
